# Agency Sales Coaching Landing Page

## How to open locally
1. Download the project folder
2. Open `index.html` in any modern browser

---

### 1. How would Google discover and index this page?
Through internal links, sitemap.xml, backlinks, and direct URL submission via Google Search Console.

### 2. What factors could prevent indexing?
- Noindex meta tag
- robots.txt blocking
- Poor server response
- Duplicate content
- JavaScript rendering issues

### 3. Would the API-loaded content be indexed?
Usually no, because it loads client-side after page load.

### 4. How to make dynamic content SEO-friendly?
- Server-side rendering
- Static generation
- Pre-rendering
- Hybrid rendering with hydration

### 5. What to check in Google Search Console?
- Index coverage
- Page experience
- Core Web Vitals
- Search queries & impressions

### 6. Google Analytics metrics for SEO success?
- Organic traffic
- Engagement time
- Bounce rate
- Conversion rate

### 7. If rankings are low after one month?
- Improve content depth
- Optimize keywords & headings
- Improve backlinks
- Improve Core Web Vitals
